# MinMicroG-MinimalProduct-A16-arm64
### MicroG Minimal version flashed to Product partition for Android 16 arm64
## This package is based on this microG version https://github.com/microg/GmsCore/releases/tag/v0.3.16.252432
## Flashing script is based on MindTheGapps script. Toybox binary is also from MTG flash zip.
## microG related issue report to official microG repo https://github.com/microg/GmsCore/issues
## Flash issue you can report in this repo
## Zip tested on Xiaomi 13 Pro with crDroid latest A16 build with crDroid recovery. Booted without any issues.
## After flash, go to microG app, check Self-check tab and allow all permissions. Some permissions are already allowed.
